# DragonMineZ 2.2 - Hotfix 8 (Minecraft 1.21.1 NeoForge)

- Fix black/magenta worn armor textures on players and NPCs, including damaged variants.
- Remove the overlapping glow copy from gathered dragon balls while retaining their pulsing full-bright appearance.
- Align summoning clouds with the camera's actual world view.
- Restore configured vehicle scale, including the occupied capsule.
- Restore the lock-on icon and correct its camera alignment.
- Project ground aura pulses onto the surface beneath the player: follow horizontal movement, remain visible up to 2 blocks above the ground, and disappear beyond that height.
- Remove regular eyebrows from the existing browless transformation hairstyle.

Validated with Java 21 build, six unit tests, 22 GameTests and packaged-JAR Minecraft clients, including Iris/Sodium with Complementary Unbound. All 291 registered armor pieces passed normal/damaged worn-texture checks. See `RENDER-VALIDATION.md` for evidence and test limits.

The mod version remains 2.2. The API from Hotfix 7 is included.
