# DragonMineZ 2.2.1 — Hotfix 33

- Fixed scream ray positions orbiting the player with the camera, and corrected charge-ray billboards inside rotated beam poses.
- Added server-controlled `MaxOverchargePercent` in `config/dragonminez/techniques.json` (default 175). Charge limits, persistence, release validation and the HUD use the synchronized limit.
- Powers continue growing with overcharge; native Kamehameha keeps its existing size behavior. Growing attacks move outward from hand/mouth attachments, overhead powers move upward, and caster-foot terrain is excluded from carving.
- Added articulated physics to clothing and weighted capes, with movement, altitude wind, Ki exertion, damping and segment limits.
- Added character height/head sliders and a dedicated body editor: leg/arm length, torso height/width, Alex/Steve body frame and bust size down to zero. Appearance changes are server-validated, saved and synchronized; older saves retain their default proportions.
- Appearance networking changed: use this version on both clients and servers.

See `docs/customization/Body-and-ki.md` for configuration and behavior details.
