# DragonMineZ 2.2.1 — Hotfix 1

- Add server runtime meters with character, combat and form scopes, transactional JSON event rules, numeric expressions and curves.
- Add meter-driven stat/drain factors and continuous form maintenance with durations, cooldowns and optional fallbacks.
- Configure independent aura layers with stable IDs, individual colors/types/opacity and explicit scale, independent of drawing order.
- Add force-relative configured dodge reactions with server collision checks, resource costs and cooldowns.
- Add optional server Lua event scripts returning validated meter changes, bounded execution and `/dmzreload scripts`.
- Expose synchronized charging, active and recovery windows for charged Ki techniques to JSON and Lua.

All new systems are configurable; no named transformation mechanic is enabled by default. This hotfix does not include the planned new flight engine or unrestricted Lua access to Java internals.
