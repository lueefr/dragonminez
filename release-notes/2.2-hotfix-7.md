# DragonMineZ 2.2 - Hotfix 7 (Minecraft 1.21.1 NeoForge)

- Locate custom NPCs with `/dmzlocate npc <id>`, including configured placements in unloaded chunks.
- Configure first-completion rewards and skill purchase conditions in optional `rules.json`.
- Set per-part scales, fur textures/tints, tail colors and eye-marking colors in form JSON.
- Control aura, lightning, energy outlines and other visual elements through contextual rules and persistent first-use history.
- Let players edit a separate hairstyle for a form with `editHair: true`, or keep the hairstyle JSON-owned with `false`.
- Extend conditions, rewards and anatomical aliases through the Java API. Full generic examples are in the fork wiki's Rules page.

External form textures belong in `config/dragonminez/form_textures/` on each client. The mod version remains 2.2.

Validation: Java 21 build, six unit tests, 21 required GameTests, language validation and isolated Minecraft client checks passed. See `RULES-VALIDATION.md` for evidence and limitations.
