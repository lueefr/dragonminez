# DragonMineZ 2.2 - Hotfix 7

Minecraft 1.21.1 NeoForge maintenance update.

### Fixed

- Corrected the camera projection and overlay depth handling for player aura outlines and sparks, which could appear displaced from the character.
- Improved muscle overlay rendering with shader packs.
- Routed Otherworld landmark placement through vanilla's per-chunk feature pipeline. The legacy Otherworld column-cache codec is retained for compatibility while the custom column-cache implementation is removed from the shipped generation graph.

### Validation

- Build completed successfully; all 8/8 GameTests passed. The packaged JAR SHA-256 is `63a7985d22ed1ca3fdf671b9c0d00652966d5f4a734550a775bce147c6f560be`.
- Aura outlines and sparks stayed aligned with the player in screenshots captured without shaders and with Iris plus Complementary Shaders r5.9.2. The muscle texture remained visible in both checks using `bodyType=1`.
- All 348 structure-template NBT files passed exact round-trip comparison.
- With Distant Horizons 3.3.1 and DH Seedgen 0.8.0, Otherworld chunk `(-1, 61)` was generated. The chunk contained an ANDESITE landmark at `(-1, 162, 980)`, and the full chunk plus a matching Distant Horizons FullData cell persisted. The FullData blob was not decoded to prove that it represents that exact landmark visually.

### Compatibility limits

- The LOD result applies only to Distant Horizons 3.3.1 with DH Seedgen 0.8.0 in the tested setup. Voxy, Voxy Seedgen, other Seedgen versions, and universal LOD compatibility were not tested.
- An LOD addon may use a generation pipeline that skips custom chunk features, including landmark placement.
- Existing cached LOD data may need rebuilding with the relevant addon's own tools. No world save or region file deletion is required by this update.

### Requirements

- Minecraft 1.21.1 and Java 21.
- NeoForge 21.1.238 or a later 21.1 release.
