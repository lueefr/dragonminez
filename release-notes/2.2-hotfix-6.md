# DragonMineZ 2.2 - Hotfix 6 (Minecraft 1.21.1 NeoForge)

- Custom NPC textures now live outside the JAR in `config/dragonminez/npc_textures/`.
- The client creates `master_base.png` from the original default texture without overwriting existing files.
- Set `baseTexture` to a PNG filename without its extension, and select the body independently with `baseModel` (`master_male`, `master_female`, or `humanoid_slim`).
- Existing JSON definitions using the old model aliases remain compatible.
- External PNG changes are detected during rendering. Armor and imported hair remain separate layers.

Install custom PNGs on each multiplayer client. Texture images are not sent by the server. Missing or invalid files fall back to the bundled default.

The mod version remains 2.2.
