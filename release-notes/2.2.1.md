# DragonMineZ 2.2.1 — Minecraft 1.21.1 NeoForge

- Integrate upstream DragonMineZ 2.2.1 and adapt difficulty scaling and gameplay changes to the NeoForge 1.21.1 port.
- Add configurable character attributes, base potential bonuses, form replacements with shared mastery, custom properties and ki-detection rules.
- Configure Shenron, Porunga and Daima Porunga wishes through JSON, including composite rewards and race/appearance changes.
- Add configurable reincarnation policies, cumulative earned-TP bonus budgets and retained-progress settings. Effect retention is independent of skill retention.
- Color transformation names from configured hair colors. Show mastery refusals above the hotbar; use nonblocking GUI notices for appropriate menu refusals.
- Fix the Mods button compatibility, charging-only Dynamic Crosshair behavior, third-person Ki occlusion and body-anchored Ki charging effects.
- Improve gradual aura mesh transitions and correct transformation model-scale behavior.

Requires Minecraft 1.21.1, Java 21, NeoForge, GeckoLib, TerraBlender and Curios for this Minecraft version. This release contains the NeoForge port; it does not contain the separate Fabric port or removed SeedGen/LOD work.
