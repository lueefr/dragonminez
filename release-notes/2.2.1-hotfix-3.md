# DragonMineZ 2.2.1 — Hotfix 3

- Configure force comparisons using normalized weights for battle power, strength, Ki power and speed.
- Use overflow-resistant arithmetic for weighted finite power scores.
- Configure reaction-attempt intervals independently for each defender, projectile and reaction rule.
- Prevent rapid rerolls from the same continuous projectile while allowing separate projectiles to trigger their own attempts.
- Keep attempt windows temporary and bounded; contacts during an attempt interval still deal damage normally.
