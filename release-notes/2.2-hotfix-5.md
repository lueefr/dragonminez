# DragonMineZ 2.2 — Hotfix 5 (Minecraft 1.21.1 NeoForge)

Custom NPCs can import complete Hair Salon exports through `hairCode`; the existing `forcedHairCode` field remains supported.

- `DMZ22:` imports a single hairstyle.
- `DMZF22:` imports a set and selects its style through `hairType`.
- Imported global, strand, tip and segment colors are preserved.
- Copy/paste whitespace and invisible separators are cleaned before decoding.
- Numeric presets retain their existing behavior; empty imported styles remain empty.

Set `hairType` to `base`, paste the complete exported value into `hairCode` in `config/dragonminez/custom_npcs/<npc>.json`, then run `/dmzreload config`. See the API Wiki for full examples and the existing definition-size limit.

Mod version remains **2.2**. Validation: six unit tests, thirteen native GameTests and an isolated Minecraft client scene with full-set/single-style imports. See `HAIRSALON-NPC-VALIDATION.md` for evidence and limits.
